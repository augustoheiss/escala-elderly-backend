## 🚀 Como Executar a API Localmente

```bash
cd escala-elderly-api
./gradlew bootRun
```

- **Porta padrão:** `http://localhost:8080`
- **Endpoint de listagem:** `GET http://localhost:8080/api/cuidadores`
